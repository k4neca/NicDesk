# Instruções para Claude Code — NicDesk

Leia e siga integralmente [`AGENTS.md`](AGENTS.md) antes de qualquer tarefa. As regras de segurança, escopo, privacidade e governança se aplicam também ao Claude Code.

**Proibição explícita:** não executar `git add`, commit, push, merge, alterações de branch ou criação/edição de issues e pull requests. Essas ações são manuais e exclusivas do mantenedor. Não editar diretamente `main`.

Por padrão, atuar como revisor do diff estável produzido pelo Codex; não editar em paralelo a mesma árvore de trabalho. Reportar evidências e pendências, sem assumir que testes ou revisão de segurança já ocorreram.
